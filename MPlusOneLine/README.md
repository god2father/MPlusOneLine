# MPlusOneLine 安装与使用

## 安装

1. 将整个 `MPlusOneLine` 文件夹复制到：
   `World of Warcraft/_retail_/Interface/AddOns/`
2. 启动《魔兽世界》正式服，在角色选择界面点击“插件”。
3. 确认 `MPlusOneLine` 已启用后进入游戏。

## 使用

在聊天栏输入 `/mplusoneline` 打开或关闭攻略面板；短别名为 `/mplo`。插件不会注册 `/mplus`，避免与其他插件冲突。

点击任意副本卡片的“发送攻略”按钮后，插件会优先发送到普通队伍频道；若没有普通队伍，则发送到副本队伍频道。两种频道都不可用时，插件仅在本地聊天框提示，不会发送消息。

面板可拖动，关闭后会记住位置；按 Esc 也能关闭。

## 赛季更新

所有攻略文本都在 `Data.lua`。新赛季时，按当前赛季副本池更新该文件中的 `addon.dungeons` 内容即可。
