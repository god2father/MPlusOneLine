# MPlusOneLine 安装与使用

## 安装

1. 将整个 `MPlusOneLine` 文件夹复制到：
   `World of Warcraft/_retail_/Interface/AddOns/`
2. 启动《魔兽世界》正式服，在角色选择界面点击“插件”。
3. 确认 `MPlusOneLine` 已启用后进入游戏。

## 使用

在聊天栏输入 `/mplusoneline` 打开或关闭攻略面板；短别名为 `/mplo`。插件不会注册 `/mplus`，避免与其他插件冲突。

界面上默认还有一个使用插件自带 `assets/cat-button.tga` 小猫图标的悬浮按钮：左键点击可打开或关闭同一面板，非战斗时左键拖动可移动，位置会保存。战斗中可以点击开关面板，但不能移动按钮；鼠标悬停可查看操作提示。

`cat-button.png` 仅为素材处理过程中的中间文件，不会由插件加载，也不包含在安装压缩包中。

面板按副本与推进顺序显示完整“首领段”：每段先是绿色的“关键小怪”卡片，再是金色的“首领”卡片。两类卡片各自对应一句话提示，并可单独点击右侧“发送”。插件会优先发送到普通队伍频道；若没有普通队伍，则发送到副本队伍频道。两种频道都不可用时，插件仅在本地聊天框提示，不会发送消息。

首次进入已收录的大秘境或毒液深渊时，面板会自动打开；同一副本内的区域刷新不会反复弹出。离开到不支持区域后，下一次进入已收录副本会再次自动打开。

面板可拖动，关闭后会记住位置；按 Esc 也能关闭。

## 赛季更新

所有攻略文本都在 `Data.lua`。新赛季时，按当前赛季副本池更新该文件中的 `addon.dungeons`，并为每个 `segments` 条目的 `trash` 与 `boss` 保留非空的 `name`、`tip` 与来源标识 `source`。只收录当前资料可核验的关键小怪机制，不要补写未经核验的机制。
