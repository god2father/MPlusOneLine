# MPlusOneLine 设计说明

## 目标

为《魔兽世界》正式服《午夜》第二赛季提供一个轻量插件：玩家可在游戏内查看当季大秘境副本的一句话攻略，并一键发送给队友。

首版优先解决开钥匙前的快速沟通，不尝试替代详细路线、首领技能百科或战斗提示插件。

## 范围

插件内置当前赛季的 8 个副本：蛇牙祭坛、谋杀街、纳洛拉克巢穴、盲谷、虚痕竞技场、王者之眠、塞塔里斯神庙、红玉新生法池。

每个副本提供一条约 40 至 70 字的中文提示，聚焦最容易造成灭团或减速的处理优先级。攻略数据完全离线内置；游戏内不访问网站、不请求网络，也不自动更新。

## 交互

玩家输入 `/mplus` 打开或关闭主面板。面板可拖动，按 Esc 可关闭，并记住上次的位置。

主面板使用副本卡片列表：卡片显示副本名称、一句话攻略和“发送攻略”按钮。首版不做搜索、筛选、词缀计算或副本内自动弹窗。

点击“发送攻略”后，插件按以下顺序选择频道：

1. 玩家在队伍中时发送到队伍频道。
2. 否则，玩家在副本队伍中时发送到副本频道。
3. 两种频道都不可用时，不发送消息，并在屏幕上给出简短原因提示。

消息格式为 `【副本名】一句话攻略`，不附加广告、网址或无关内容。

## 架构

插件目录包含 TOC 清单、主控制器、攻略数据和 README 四类文件。

- TOC 声明正式服接口版本及加载顺序。
- 数据模块只负责提供副本名和攻略文本。
- 主模块创建面板、注册 `/mplus` 命令并处理频道选择和发送。
- README 说明安装位置、使用方式及赛季更新时应替换的数据文件。

攻略数据与 UI、聊天逻辑隔离，因此赛季更新时可单独替换数据而不改动界面或发送逻辑。

## 错误处理

缺失副本数据时，按钮不发送并提示“暂未收录该副本攻略”。无法确定合法聊天频道时，按钮不抛错，只显示本地提示。所有用户输入均不参与代码执行。

## 验收标准

1. 正式服客户端能加载插件且无 Lua 报错。
2. `/mplus` 能稳定显示和隐藏面板。
3. 8 个副本均显示名称、攻略与发送按钮。
4. 组队时发送到队伍频道；仅在副本队伍时发送到副本频道；无可用频道时不发送且有提示。
5. 关闭并重新打开面板后，位置保持不变。
6. README 可让玩家将插件安装到 `Interface/AddOns` 并完成基本使用。

## 非目标

- 不在战斗中自动播报。
- 不解析当前钥石、副本或词缀。
- 不提供详细路线图、计时器或战斗提示。
- 不在游戏内联网或同步第三方内容。
