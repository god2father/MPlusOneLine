# MPlusOneLine

`MPlusOneLine` 是一个《魔兽世界》正式服插件：在游戏内按副本展示当前赛季大秘境的逐首领一句话中文攻略，并支持逐条发送给队友。

## 当前收录

- 蛇牙祭坛
- 谋杀街
- 纳洛拉克巢穴
- 盲谷
- 虚痕竞技场
- 王者之眠
- 塞塔里斯神庙
- 红玉新生法池

攻略完全内置，不会在游戏内联网或同步第三方内容。它适合开钥匙前快速统一重点，不替代详细路线、计时器或战斗提示插件。每条提示均为对公开攻略的中文短句归纳，不是原文转载；赛季副本池与逐本攻略来源见 [SOURCES.md](SOURCES.md)。

## 安装

将 [`MPlusOneLine`](MPlusOneLine) 文件夹复制到：

```text
World of Warcraft/_retail_/Interface/AddOns/
```

在角色选择界面启用插件。详细步骤见 [插件安装说明](MPlusOneLine/README.md)。

## 使用

输入 `/mplusoneline` 打开或关闭面板；短别名为 `/mplo`。插件不会注册 `/mplus`，避免与其他插件冲突。

屏幕上还会显示一个使用插件自带小猫图标的悬浮按钮（`MPlusOneLine/assets/cat-button.tga`）。左键点击与上述命令相同，可打开或关闭面板；非战斗时可左键拖动按钮，位置会在重载界面后恢复。战斗中仍可点击开关面板，但不能移动按钮。

安装包仅包含运行时所需的 TGA 图标；`cat-button.png` 是处理用中间文件，不会被插件引用或打包。

大秘境面板以副本和推进顺序分组：每个“首领段”先显示进入该首领前的关键小怪，再显示该首领；两张卡片均可单独发送。进入已收录的团队副本时，面板会自动切换为当前难度的全部团本首领，保持相同的逐条发送方式。

首次进入已收录的 8 个大秘境或毒液深渊时，插件会自动打开面板；同一实例内不会因区域刷新反复弹出，离开到不支持区域后才重置自动打开状态。

## 更新赛季数据

编辑 [`MPlusOneLine/Data.lua`](MPlusOneLine/Data.lua) 中的 `addon.dungeons`；每个副本的 `segments` 列表中，`trash` 与 `boss` 均应保留非空的 `name`、`tip` 与可追溯 `source`。界面和聊天逻辑不需要随副本池一起修改。

## 正式服 12.1.0 兼容性

本版本的 TOC 为 `## Interface: 120100`，对应当前《午夜》12.1.0 正式服。团本自动识别只使用正式服仍支持的 `GetInstanceInfo()` 以及 `PLAYER_ENTERING_WORLD`、`ZONE_CHANGED_NEW_AREA`、`PLAYER_DIFFICULTY_CHANGED`、`UPDATE_INSTANCE_INFO` 事件。

源码与接口版本已核验，但本机没有可启动的 `_retail_` 客户端，因此尚未进行游戏内加载测试。请在最新版正式服安装后执行以下最终验证：

1. 在聊天栏输入 `/dump (select(4, GetBuildInfo()))`，确认输出为 `120100`。
2. 输入 `/mplusoneline`，再点击小猫悬浮按钮，确认两者都能开关面板且没有 Lua 报错；非战斗拖动按钮、重载界面后确认位置恢复。
3. 进入任一收录大秘境，确认面板自动打开；离开后进入不支持区域，确认不会弹出。再次进入收录副本时应重新自动打开。
4. 打开任一大秘境，确认每个首领段先显示绿色“关键小怪”卡片、后显示金色“首领”卡片；分别点击两类“发送”，确认聊天内容与卡片一致。
5. 进入/离开毒液深渊，并切换团队查找器、普通、英雄或史诗难度，确认面板会自动打开/刷新为对应首领提示。
